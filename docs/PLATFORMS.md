# Platforms: what runs on Windows, what runs on Linux

Generated by `fieldkit parity os --write` from `fieldkit/desk/os_parity.yaml`, the tool cards (`fieldkit/desk/tools.yaml`), the pipelines and recipes, the skills, the workflows, the hooks and the modules. Do not edit by hand. Same output on Windows and Linux: it reads files in the repo only.

71 tool cards run on one system only: 34 to port, 6 with an equivalent on the other system, 31 native-only.

- **PORT**: doable; the other system's mechanism is named, the lowest `#` goes first.
- **EQUIVALENT**: the other system has a card or command that does the job.
- **NATIVE-ONLY**: a hardware or OS feature that does not exist on the other side.

A new single-system card, stage, skill, workflow step, hook or module guard fails CI until it has a record (`fieldkit/desk/platformcheck.py`, `fieldkit parity os`).
