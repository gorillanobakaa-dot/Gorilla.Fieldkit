# Platforms: what runs on Windows, what runs on Linux

Generated by `fieldkit parity os --write` from `fieldkit/desk/os_parity.yaml` and the tool cards (`fieldkit/desk/tools.yaml`). Do not edit by hand.

74 tool cards run on one system only: 37 to port, 6 with an equivalent on the other system, 31 native-only.

- **PORT**: doable; the other system's mechanism is named, the lowest `#` goes first.
- **EQUIVALENT**: the other system has a card or command that does the job.
- **NATIVE-ONLY**: a hardware or OS feature that does not exist on the other side.

A new single-system card fails CI until it has a row (`fieldkit/desk/platformcheck.py`).
