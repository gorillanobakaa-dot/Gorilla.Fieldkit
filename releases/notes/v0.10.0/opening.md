## What this is

Fieldkit v0.10.0: the harness builds a whole product with one command (`fieldkit emerge`), on Linux and Windows alike, asks the owner everything it may need once before the job starts, and lets coding agents and Antigravity sessions coordinate and transfer files directly over the cable.

## Should you download it?

Yes, on both computers (the ThinkPad and the VAIO). Installing is unchanged: the install script, or `fieldkit update`. It is the first release since v0.9.4 (242 non-merge commits across 166 pull requests).

## Why this matters

On 2026-11-17 the Firefox 160 release for Linux, Windows and old Macs went out from this code: the builds, the checks that each machine's build matches the public patch set, and one Latest release page carrying every system's file. The same release cycle closed key harness gaps — a quota guard that blocked Claude with credit left, a one-OS-per-day release rule, a green build step without building, missing Windows installer verification, and one-way cable handoffs — while adding direct Desktop/Downloads/Documents transfers over the cable and a bidirectional Antigravity GUI/CLI bridge.
