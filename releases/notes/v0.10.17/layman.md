# Fieldkit v0.10.17 in plain language

Use `fieldkit handoff --list` to find saved sessions. Preview a handoff with `fieldkit handoff ID --provider codex --dry-run`. Review the local card before approving a launch. The selected remote provider receives context from the card when its client reads it.

Use `fieldkit network --help` to see the available connection checks. The commands help distinguish a local connection problem from trouble reaching the internet.

The completion instructions now keep a conversation open while its owner is using it. An agent working on Fieldkit must verify the public release before reporting the work done.
