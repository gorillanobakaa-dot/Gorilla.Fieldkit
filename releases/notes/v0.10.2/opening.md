## What this is

Fieldkit v0.10.2 adds cleanup for old coding-agent sessions, native Zero inbox hooks for Codex, Gemini CLI, and Antigravity, and an automatic Windows and Linux release check.

## Should you download it?

Install this update if you use Fieldkit to prepare capture lessons or coordinate coding agents through Zero.

## Why this matters

Lessons start with a clean capture window. Cleanup runs without a model call, and agents can see pending Zero messages through their existing clients while they work.
