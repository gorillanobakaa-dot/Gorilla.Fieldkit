# v0.10.1, in plain language

## Start a lesson with a clean workspace

The cleanup preview shows what Fieldkit finds in temporary folders and supported agent session stores. A retention age such as three days keeps recent work. Active sessions, worktrees, and Fieldkit's own scripts stay protected.

For a transcript Fieldkit can verify is old and closed, it checks a local archive before sending the original to the Windows Recycle Bin or Linux Trash. The preview shows which sources remain protected. Cleanup and verification run without a model call.

## Receive messages while you work

Zero can show inbox traffic in Codex, Gemini CLI, and Antigravity. Once an agent checks in through its hook, other stations can address it by name. The hook checks for messages when the session starts or the agent next runs a supported event. Messages stay queued during idle periods.

Hook status shows configuration and live check-ins separately. Codex requires its own hook trust review before running a new hook.
